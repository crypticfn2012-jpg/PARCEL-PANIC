# PARCEL PANIC

A stylised 3D browser delivery party game. The first milestone builds the playable core loop; online multiplayer and account-backed progression are separate subsequent milestones.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Current status

- Milestone 1: core 3D gameplay foundation.
- AI runners are local computer-controlled opponents, not online players.
- Multiplayer, server persistence, CrazyGames SDK and progression systems are not yet implemented.
